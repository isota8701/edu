## 오늘의 단원: 더하기·빼기 **섞어서** 똑똑하게 + 길이 맛보기 (3단원 3세션)
예상 시간: 약 35~40분

지난 시간엔 "빼기 똑똑하게 빼는 두 길"과 수열을 잘 해냈어요. 그런데 **빼기만 줄줄이 풀다 보니**,
받아내림 없는 쉬운 빼기도 괜히 복잡하게 풀거나, 갑자기 더하기가 나오면 헷갈리는 모습이 있었지요.

> 그래서 오늘의 핵심은 **"풀기 전에 잠깐 멈춰서 한마디"** 예요.
> 문제를 보면 풀기 전에 **"이건 더하기야, 빼기야? 받아올림(받아내림) 있어?"** 를 **소리 내어 한 번** 말하고 시작합니다.
> 이 한마디가 "지금 내가 무슨 셈을 하고 있는지"를 아이 스스로 알아차리게 해 줘요. (그래서 더하기·빼기를 **일부러 섞어** 냈어요.)

그리고 학교가 곧 들어갈(이미 시작한) **길이 재기(cm)** 를 워밍업에서 가볍게 맛봅니다.

## 1. 워밍업 (6~7분)

> 압박 없이 "같이 생각해보자" 톤으로. 종이와 연필 준비.

**(워밍업1) 연산 식별 준비 — "더하기야, 빼기야?"**
부모가 식을 하나씩 보여 주고, **풀지 말고** 무슨 셈인지만 빠르게 말하게 하세요.
- `40 + 30` → "더하기!" / `50 - 20` → "빼기!" / `27 + 6` → "더하기, 받아올림 있어!" / `34 - 8` → "빼기, 받아내림 있어!"
"오늘은 **풀기 전에 이렇게 한마디 하는 게** 우리 약속이야." (오늘 내내 쓸 습관을 여기서 가볍게 심어요.)

**(워밍업2) 길이 맛보기 — cm가 뭐였더라?** *(학교 길이 단원 준비)*
세 가지를 말로만 가볍게:
- **단위 고르기**: "연필 길이는 **cm**로 잴까, **m**로 잴까?"(→cm) "교실 긴 쪽은?"(→m) "지우개는?"(→cm) — *작은 물건은 작은 단위(cm), 큰 것은 큰 단위(m).*
- **어림 — 어디에 더 가까울까**: "어떤 막대를 자로 쟀더니 **27cm** 였어. 이건 **20cm와 30cm 중 어디에 더 가까워?**"(→30cm) "왜?"(→27은 30까지 3, 20까지 7이니까 30이 더 가까워)
- **비교 문장 한 조각씩 읽기**: "막대를 눈으로 **어림했더니 4cm**, 자로 **재 보니 5cm** 였어. 그럼 **어림한 길이(4)는 / 잰 길이(5)보다 / 더 (길까, 짧을까)?**"(→짧다) — 천천히 끊어 읽으며 "4가 5보다? 작지! 그러니까 더 **짧다**." 한 조각씩 짚어 주세요.

> 부모용 한 줄: 계산이 아니라 **단위 감각·어림·문장을 천천히 읽는 논리**가 길이의 핵심이에요. 오늘은 맛보기, 다음에 본격적으로 다뤄요.

**(워밍업3) 구구단 짧게 (1분)**
6씩 리듬: "6, 12, 18, 24, 30, 36…"(손뼉) / 빈칸: `6 × ___ = 30` / 랜덤: `4 × 8 = ?`

## 2. 개념 확인 (3분)

**오늘의 핵심 한 줄**: 문제를 보면 풀기 전에 **"더하기야 빼기야? 받아올림(내림) 있어?"** 를 한 번 말하고 시작한다.

같은 두 수 `45`와 `27`로 보여 주세요.
- `45 + 27` → "**더하기**. 5+7=12라 **받아올림 있어.**" (→ 72)
- `45 - 27` → "**빼기**. 5에서 7을 못 빼니 **받아내림 있어.**" (→ 18)

"같은 두 수인데 **더하기냐 빼기냐에 따라 완전히 달라지지?** 그래서 **먼저 무슨 셈인지 알아차리는 게** 제일 중요해."
→ 유주가 "더하기/빼기, 받아올림/내림 있다/없다"를 **말로 한 번** 하게 해 주세요.

## 3. 본문제 — 더하기·빼기 섞기 (핵심, 15~17분)

> ⭐ **규칙: 각 문제를 풀기 전에 `[말로 한마디]` 칸을 먼저 채우게 하세요.** "더하기야 빼기야? 받아올림/내림 있어?"
> 답보다 **"먼저 알아차리고 → 그에 맞는 길로 푸는 것"** 을 칭찬해 주세요.

**(1) [새 진도 — 혼합]**
```
[말로 한마디]  이건 (   )기, 받아올림(받아내림) ( 있다 / 없다 )
47 + 28 = ___
```
→ 답: 75 · (더하기, 받아올림 있다) — 십 만들기: `47+3=50, 50+25=75` 또는 보정: `47+30=77, 77-2=75`

**(2) [새 진도 — 혼합]** *받아내림 없는 빼기 — 괜히 어렵게 풀지 않기*
```
[말로 한마디]  (   )기, 받아내림 ( 있다 / 없다 )
68 - 25 = ___
```
→ 답: 43 · (빼기, **받아내림 없다**) — "없으면 그냥 자리별로!" `60-20=40, 8-5=3 → 43`
> 포인트: 받아내림이 **없으면** 보정·십 만들기 같은 복잡한 길이 **필요 없어요.** "없네? 그럼 바로!" 를 짚어 주세요. (지난번 "쉬운 빼기도 복잡하게 풀던" 모습 교정)

**(3) [새 진도 — 혼합]**
```
[말로 한마디]  (   )기, 받아내림 ( 있다 / 없다 )
73 - 29 = ___
```
→ 답: 44 · (빼기, 받아내림 있다) — 보정: `73-30=43, 43+1=44` (29는 30보다 1 작으니 1 도로 더하기)

**(4) [새 진도 — 혼합]**
```
[말로 한마디]  (   )기, 받아올림 ( 있다 / 없다 )
35 + 42 = ___
```
→ 답: 77 · (더하기, 받아올림 없다) — 자리별: `30+40=70, 5+2=7 → 77`

**(5) [누적 — 전략 선택·연산 식별 종합] 무슨 셈? 어느 길이 똑똑?**
세 식을 보여 주고, **풀기 전에** 각각 ①무슨 셈인지 ②받아올림/내림 있는지 ③**어떻게 푸는 게 똑똑한지** 말하게 하세요.
- ㉮ `50 - 20` → (빼기, 받아내림 없다 → 그냥 바로) = 30
- ㉯ `64 + 29` → (더하기, 받아올림 있다 → 보정: 64+30-1) = 93
- ㉰ `56 - 23` → (빼기, 받아내림 없다 → 자리별로 바로) = 33
> ⭐ 정답보다 **"먼저 알아차리고 길을 고른 것"** 을 칭찬. 오늘 사고력의 핵심이에요.

## 4. 본문제 — 거꾸로 풀기 순서도 (10분)

> 지난 시간 도전에서 "거꾸로 풀기"를 어려워했어요. 오늘은 **도전이 아니라 본문제로 내려서, 순서도 칸을 같이 채우며** 천천히 익혀요. (방법을 손에 익히는 게 목표)

**(6) [새 진도 — 역방향 추론, 순서도 칸 채우기] 처음 몇 개였을까?**
부모가 천천히 읽어 주세요:
"유주가 구슬을 몇 개 가지고 있었어. 친구에게 **12개를 줬고**, 그다음 누나가 **20개를 더 줬어.** 그랬더니 지금 **35개**가 됐어. **처음에 몇 개 있었을까?**"

먼저 순서도를 같이 그려요:
```
처음 ?  →(친구에게 12개 줌, -12)→  ?  →(누나가 20개 줌, +20)→  35
```
이제 **맨 끝 35에서 거꾸로** 거슬러 갑니다. **규칙: 받은 건 도로 빼고, 준 건 도로 더해요.**
```
① 누나가 준 20개를 도로 빼기:   35 - 20 = ___      → (15)
② 친구에게 준 12개를 도로 더하기: 15 + 12 = ___      → (27)
```
→ 답: **27개**
> ⭐ **검산 한 번**: "처음 27개 → 12개 주면 15개 → 20개 받으면 35개. 맞네!" 답이 나오면 꼭 거꾸로 한 번 확인하는 습관을 들여 주세요.
> 막혀도 괜찮아요. **순서도 칸을 같이 채우는 것** 자체가 오늘의 연습이에요.

## 5. 본문제 — 내려가는 수열 (6분)

> 유주가 잘하고 좋아하는 수열이에요. 안에 **빼기 연습**이 숨어 있어요.

**(7) [누적 — 규칙 수열 + 두 자리 빼기]**
```
81, 74, 67, 60, ___, ___
```
"몇씩 작아지고 있어? 다음 **두 칸**을 채워 보자. (그리고 `60 - 7`을 똑똑하게 빼 볼래?)"
→ 답: **53, 46** (7씩 작아짐)
> `60-7=53`, `53-7=46` — 받아내림 빼기를 좋아하는 수열 안에서 자연스럽게 연습해요. "여기도 빼기네? 받아내림 있어?" 한 번 짚어 주면 오늘 주제와 연결돼요.

## 6. 사고력 도전 (8분)

> "이건 어른도 잠깐 멈춰. 끝까지 못 풀어도 괜찮아 — **어디까지 생각했는지가 중요해.**"
> 1분쯤 스스로 생각하게 기다렸다가, 막히면 힌트를 **점점 작게** 주세요.

**(도전1) [조건 추론 / 논리] 나는 누구일까?**
"나는 **두 자리 수**야.
- 십의 자리 숫자와 일의 자리 숫자를 **더하면 9**.
- 십의 자리가 일의 자리보다 **3 더 커.**
나는 누구일까?"
- 1단계 힌트: "두 숫자를 더하면 9가 되는 짝을 적어 보자. (0,9)(1,8)(2,7)(3,6)…"
- 2단계 힌트: "그중에서 **십의 자리가 3 더 큰** 짝은? 큰 수 - 작은 수 = 3인 짝을 찾아."
→ 답: **63** (6+3=9, 6-3=3)
> 짝을 차례로 적어 따져 보는 **체계적 탐색**이 핵심. 답을 맞히면 "왜 63 하나뿐이야?" 도 물어봐 주세요.

**(도전2) [공간·도형 패턴] 점이 몇 개로 자랄까?**
> (도전1은 숫자 조건을 따지는 문제, 도전2는 **모양이 자라는 규칙**을 보는 다른 종류예요.)
점으로 만든 **정사각형**이 점점 커져요.
```
●        ● ●        ● ● ●
         ● ●        ● ● ●
                    ● ● ●
1개        4개         9개        →  ?
```
"한 변이 1칸, 2칸, 3칸으로 자라고 있어. 점은 **1개 → 4개 → 9개**. **다음(한 변 4칸)은 점이 몇 개일까?**"
- 힌트: "한 줄에 4개씩, 줄도 4줄이면?" (또는 "9에서 몇 개 늘었지? 1→4는 +3, 4→9는 +5, 다음은 +7")
→ 답: **16개** (한 변 4칸 → 4×4=16, 또는 9+7)
> 두 가지 길 다 좋아요: ① 한 줄 개수 × 줄 수(곱셈 연결) ② 늘어나는 양이 +3, +5, +7로 커진다(규칙). 어느 쪽으로 설명해도 크게 칭찬!
