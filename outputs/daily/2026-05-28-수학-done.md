## 1. 워밍업 (5분)

> 부드럽게 시작해요. 종이와 연필 준비. "같이 생각해보자" 톤으로, 압박 없이.

**(워밍업1) 보정 준비 — 가까운 십 찾기 + 몇십 빼기**
부모가 말로 물어보세요:
- "**28은 어느 깔끔한 십에 가깝지?**" (→ 30, 28보다 2 큼)
- "**19는? 39는?**" (→ 20 / 40, 각각 1씩 큼)
- 그다음 몇십 빼기(쉬운 빼기): "**62 - 30은?**"(→32) "**75 - 40은?**"(→35) "**53 - 20은?**"(→33)
"몇십을 빼는 건 쉽지? 오늘은 이걸 이용해서 어려운 빼기를 쉽게 만들 거야."

**(워밍업2) 십 만들기 준비 — 한 자리 빼서 깔끔한 십 만들기**
- "**42에서 2를 빼면?**"(→40) "**64에서 4를 빼면?**"(→60) "**71에서 1을 빼면?**"(→70)
- 이어서: "**40 - 6은?**"(→34) "**60 - 7은?**"(→53) "**70 - 8은?**"(→62)
"봐, **깔끔한 십을 만든 다음엔 한 자리 수만 빼면 되니까** 금방 풀리지? 이게 오늘의 두 번째 무기야."

## 2. 개념 확인 (3분)

**오늘의 핵심 한 줄**: 두 자리 빼기는 **① 빼는 수를 깔끔한 십으로 바꿔 빼고 도로 돌려주기**, 또는 **② 깔끔한 십을 만들어 한 자리씩 빼기** 로 쉬워진다. 그리고 **세로셈은 언제나 믿을 수 있는 길**이다.

같은 문제 `62 - 28`을 두 길로 보여 주세요.

**길 ㉠ (보정 — 빼는 수를 깔끔한 십으로):**
"28은 빼기 어렵지만 **30은 쉽지.** `62 - 30 = 32`. 그런데 30은 28보다 **2 더 크니까 2를 더 뺀 거야.** 그러니 **2를 도로 더해** → `32 + 2 = 34`."

**길 ㉡ (십 만들기 — 한 자리만 남기기):**
"`62 - 20 = 42` (십의 자리 먼저). 이제 8을 빼는데, **42를 40으로 먼저 만들고**(`42 - 2 = 40`), **남은 6을 빼자**(`40 - 6 = 34`)."

부모가 던질 질문 (등호 — 짧게):
"두 길 다 **34**가 나왔지? `62 - 28` 과 `62 - 30 + 2`는 **모양만 다르고 양은 똑같아.** 그게 등호(=)의 뜻이야." → 유주가 "응, 같아"라고 **한 번 말로** 하게 해 주세요.

## 3. 본문제 A — 두 자리 빼기 (핵심, 15~17분)

> 오늘의 중심이에요. 부모가 칸을 그려 주고, 유주가 채웁니다. **답보다 "어떻게 쉽게 만들었는지"**를 같이 봐 주세요.

**(1) [새 진도 — 보정, 안내된 단계] 빼는 수를 깔끔한 십으로**
```
53 - 29
①  29를 30으로 보고 빼기:  53 - 30 = ___
②  30은 29보다 1 크니까(1 더 뺐으니까) 도로 더하기:  ___ + 1 = ___
```
→ 답: ① 23  ② 23, 24
"왜 1을 도로 더했어?" 한 번 물어봐 주세요. (→ 30이 29보다 1 더 커서, 1을 더 뺐으니까)

**(2) [새 진도 — 보정, 스스로 정하기] 이번엔 유주가**
```
62 - 28
①  28을 어느 십으로 볼까?  62 - ___ = ___
②  그만큼 도로 더하기:  ___ + ___ = ___
```
→ 답: ① 30, 32  ② 32, 2, 34
> 가까운 십(30)과 돌려줄 수(2)를 **유주가 스스로** 정하게 하세요. 막히면 워밍업1을 떠올리게.

**(3) [새 진도 — 십 만들기, 한 자리만 남기기] 단계로 빼기**
```
71 - 38
①  십의 자리 먼저:  71 - 30 = ___
②  남은 8 빼기 — 먼저 40 만들기:  41 - 1 = ___
③  남은 7 빼기:  40 - 7 = ___
```
→ 답: ① 41  ② 40  ③ 33
> 핵심: **40(깔끔한 십)을 만든 뒤엔 한 자리(7)만 빼면 된다.** 8을 1+7로 가른 게 포인트예요(1은 40을 만드는 데, 7은 나머지).

**(4) [누적 복습 — 한 문제, 두 길] 45 - 19를 두 방법으로**
같은 문제를 두 번, 다른 길로 풀어요.
- 길 ㉠ (보정): `45 - 20 = 25` → `25 + 1 = ___` (19는 20보다 1 작으니 1 도로 더하기) → 26
- 길 ㉡ (세로셈, 받아내림): `45 - 19 = ___` → 26
"길이 달라도 **둘 다 26.** 길이 달라도 도착지는 같아." (등호 의미 + 세로셈은 믿음직한 길)

**(5) [새 진도 — 전략 선택, 말로 설명] 어떤 길이 똑똑할까?**
세 문제를 보여 주고, **푸는 것보다** "각각 **어떻게 빼면 가장 똑똑할지** 고르고 **왜인지 말해줘.**"
- ㉮ `80 - 40 = ?`  → (몇십 - 몇십이라 **그냥 바로**)
- ㉯ `64 - 29 = ?`  → (29가 30에 가까우니 **보정**이 편함)
- ㉰ `56 - 23 = ?`  → (23은 십에 안 가까움 → **세로셈** 또는 십의 자리부터)
→ 참고 답: ㉮ 40 / ㉯ 35 / ㉰ 33
> 정답보다 **고른 이유를 말로 설명하는 것**을 칭찬해 주세요. "이 빼기엔 이 길이 똑똑해"를 스스로 판단하는 게 오늘 사고력의 핵심이에요.

## 4. 본문제 B — 규칙·수열 (사고력, 10~12분)

> 유주가 잘하고 좋아하는 영역이에요. 쉬운 것 하나로 몸을 풀고, **사고력 문제 두 개**로 한 걸음 더 갑니다.

**(6) [복습 — 쉬운 규칙으로 워밍업] 무엇씩 커질까?**
```
3, 6, 9, 12, ___, ___
```
→ 답: 15, 18 (3씩 커짐) — "이거 무슨 단 같아?"(3단) 한마디만.

**(7) [사고력 — 내려가는 수열, 뺄셈과 연결] 무엇씩 작아질까?**
```
84, 76, 68, 60, ___, ___
```
"규칙을 찾아서 다음 **두 칸**을 채워보자. 그리고 **60 - 8을 똑똑하게** 빼볼래?"
→ 답: 52, 44 (8씩 작아짐)
> 내려가는 규칙을 찾는 동시에 **두 자리 빼기(60-8=52, 52-8=44)를 자연스럽게 연습**해요. 빼기가 약한 부분을 좋아하는 수열 안에서 만나게 한 거예요.

**(8) [사고력 — 간격이 커지는 수열] 뛰는 칸이 점점 커져!**
```
1, 2, 4, 7, 11, ___
```
"이번엔 한 칸씩 더할 때 **뛰는 양이 점점 커져.** 1씩? 2씩? 잘 봐."
→ 답: 16 (차이가 +1, +2, +3, +4, **+5**)
> 막히면 칸 사이에 화살표를 그리고 "**여기는 얼마 늘었지?**"를 하나씩 적어 보게 하세요(+1→+2→+3→+4). 규칙(차이가 1씩 커진다)을 스스로 말하면 크게 칭찬!

## 5. 사고력 도전 (8분)

> "이건 어른도 잠깐 멈춰. 끝까지 못 풀어도 괜찮아. **어디까지 생각했는지가 중요해.**"
> scaffolding은 처음엔 주지 말고, 1분쯤 스스로 떠올리게 기다려 주세요. 막히면 힌트를 **점점 작게**.

**(도전1) [거꾸로 풀기 / 역방향 — 확신 + 검산] 사라진 처음 수**
부모가 천천히 읽어 주세요:
"유주가 사탕을 몇 개 가지고 있었어. 동생한테 **18개를 줬고**, 그다음 엄마가 **25개를 더 줬어.** 그랬더니 지금 **41개**가 됐어. **처음에 몇 개 있었을까?**"

- 1단계 힌트(필요할 때): 순서도 → `처음 ?  →(-18)→  ?  →(+25)→  41`. "마지막 41에서 **거꾸로** 거슬러 가자. 마지막에 25개 받았으니, 받기 전에는?" (41 - 25 = 16)
- 2단계 힌트: "그 전에 18개를 줬었지? 주기 전에는 더 많았을 거야." (16 + 18 = 34)
→ 답: **34개**
> ⭐ 유주는 거꾸로 풀기 **방법은 스스로 맞게 떠올리는데, 확신이 없어 계산하다 멈출 수 있어요.**
> - 접근이 맞으면 **"그 방법 맞아, 끝까지 한번 가보자"** 하고 확신을 주세요.
> - 답(34)이 나오면 **검산 한 번**: "처음 34개 → 18개 주면 16개 → 25개 받으면 41개. 맞네!"
> 거꾸로 갈 땐 **받은 건 빼고, 준 건 더해요.** (41-25=16은 오늘 배운 보정으로: 41-25 = 41-20-5 = 21-5 = 16)

**(도전2) [규칙 발견 — 숨은 규칙이 두 개] 번갈아 나오는 수열**
> (도전1은 거꾸로 거슬러 가는 역방향이었어요. 도전2는 **규칙을 찾아 다음을 예측**하는 다른 축, 게다가 규칙이 **두 개 숨어** 있어요.)
```
1, 10, 2, 20, 3, 30, ___, ___
```
"숨은 규칙이 **두 개**야. **하나 걸러 하나씩** 보면 보일 거야."
- 힌트(필요할 때): "**첫째·셋째·다섯째** 수만 봐: 1, 2, 3… 다음은?" (→ 4) / "**둘째·넷째·여섯째**만 봐: 10, 20, 30… 다음은?" (→ 40)
→ 답: 4, 40
> 두 수열이 번갈아 끼어 있다는 걸 알아채는 게 핵심이에요. 한 줄로 보면 헷갈리지만 **번갈아 떼어 보면** 규칙이 둘 다 보여요.

### ⭐ 부모님 질문에 대한 답 — "십 만들기 빼기, 어떤 사고 과정인가?"
- 예전 자료의 `62 - 2 - 26 = 60 - 26`은 **잘못된 십 만들기**였어요. 60(깔끔한 십)을 만들어도 **여전히 26(두 자리)을 빼야** 해서 하나도 안 쉬워집니다. 부모님 지적이 정확해요.
- **십 만들기는 "십을 만든 뒤 빼는 양이 한 자리 수로 줄어들 때만" 진짜 쉬워집니다.** (예: 40 - 6, 70 - 8) 두 자리가 남으면 의미가 없어요.
- 그래서 두 자리 빼기엔 다음 **두 가지 사고 과정** 중 하나를 씁니다:
  - **㉠ 보정** (빼는 수가 십에 가까울 때 — 28·19·39 등): "**어려운 수 대신 가까운 십을 빼고, 더 뺀 만큼 도로 더한다.**" → `62-28 = 62-30+2 = 34`. *빼는 수를 올려서 깔끔하게 만들면, 올린 만큼 다시 더해준다.*
  - **㉡ 십 만들기(한 자리 남기기)**: "**십의 자리를 먼저 빼고, 남은 한 자리는 깔끔한 십을 만들어 한 자리씩 뺀다.**" → `62-28 = 62-20-8 = 42-8 = 42-2-6 = 40-6 = 34`. (여기서 8을 2+6으로 가르는 이유: 2는 40을 만드는 데, 6은 나머지.)
- **이건 머리셈(암산) 전략**이에요. **세로셈은 언제나 믿을 수 있는 길**로 두고, 위 두 길은 "더 빠르고 똑똑하게" 풀 때 고르는 거예요. (5)번이 바로 "언제 어떤 길이 똑똑한가"를 고르는 연습입니다.

### 오늘 지도에서 꼭 챙길 것
- **두 자리 빼기 두 길**((1)~(4)): 보정(빼는 수를 십으로 +도로 더하기)과 십 만들기(한 자리만 남기기). **"십 만든 뒤 한 자리만 빼면 쉽다"**를 손으로 체감하게.
- **전략 선택**((5)): 답보다 **"왜 그 길?"을 말로**. 자신감 + 사고 과정 표현.
- **규칙·수열 사고력**((7)(8)·도전2): 단순 반복이 아니라 내려가는 규칙·커지는 간격·두 규칙 번갈아 — 화살표로 간격 적어 보기.
- **검산 습관**(도전1): 답 나오면 한 번 되짚기. "방법은 맞는데 확신 부족" 약점에 직결 — **"그 방법 맞아, 끝까지"** + 검산.
- 도전에서 막히면 **힌트를 작은 것부터**, 못 풀어도 "여기까지 생각한 게 멋지다"로 마무리.
