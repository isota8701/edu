## 2. 개념 확인 (3~4분) — 말이 식을 알려 준다

**오늘의 핵심 개념**: 문제의 말에는 어떤 식으로 바꿔야 하는지 힌트가 숨어 있다.
- "모두 몇 개" → 합치는 말 (더하기, 또는 같은 수가 여러 묶음이면 곱하기)
- "남은 것은 / 몇 개 더 많은가" → 비교·덜어내는 말 (빼기)

부모가 던질 질문 (말만 듣고 +·−·× 중 고르기, 계산은 아직 안 함):

1. "사탕이 5개씩 4봉지 있어. **모두** 몇 개일까?" → 어떤 식? (같은 수 묶음 → 곱하기)
2. "사탕 20개 중에 7개를 먹었어. **남은 것은**?" → 어떤 식? (빼기)
3. "형은 15개, 동생은 9개. 형이 **몇 개 더 많아**?" → 어떤 식? (빼기)

> 지도 포인트: 답을 구하지 말고 **"이건 ×야 / −야"라고 말로만** 고르게 한다. 직전 세션에 35−32인지 35+32인지 잠깐 헷갈렸던 그 지점이다.

## 3. 본문제 (20~25분)

### (1) 같은 수 반복 더하기 = 곱셈 [새 진도 — 곱셈 의미]

색종이가 한 묶음에 5장씩 있습니다. 4묶음 있습니다.

```
덧셈으로:  5 + 5 + 5 + 5 = □
곱셈으로:  5 × 4 = □
```

> 부모 멘트: "더하기로 쓴 식과 곱하기로 쓴 식의 답이 같지? 곱하기는 같은 수를 여러 번 더한 걸 짧게 쓴 거야."

---

### (2) 점 배열을 두 가지 식으로 읽기 [새 진도 — 배열 모델]

점이 이렇게 놓여 있습니다.

```
● ● ● ● ●
● ● ● ● ●
● ● ● ● ●
```

- 한 줄에 5개씩 3줄 → 식: 5 × 3 = □
- 세로로 보면 한 줄에 3개씩 5줄 → 식: 3 × 5 = □

질문: 점의 **전체 개수**는 두 식 모두 같나요? 왜 그럴까요?

> 부모 멘트: "묶는 방향을 바꿔도 점의 수는 안 변하지? 그래서 두 식의 답이 같아." (※ 이 한 번만 짚고 넘어갑니다. 더 깊게 반복하지 않습니다.)

---

### (3) 곱셈식 ↔ 덧셈식 서로 바꾸기 [새 진도 — 식 변환]

빈칸을 채워 보세요.

```
5 × 6  →  5 + 5 + 5 + 5 + 5 + 5 = □
3 + 3 + 3 + 3  →  3 × □ = □
```

질문: 5를 몇 번 더했나요? 3은 몇 번 더했나요?

---

### (4) 6단을 아주 살짝 만나기 [새 진도 — 6단 첫 노출]

연필을 6자루씩 봉지에 담습니다. 6씩 뛰어 세어 봅니다.

```
6 — 12 — 18 — □ — □
```

질문: 2봉지면 연필은 몇 자루? (6×2) / 3봉지면? (6×3)

> 부모 멘트: "오늘은 6단을 처음 살짝 인사만 하는 거야. 다 못 외워도 돼. 6씩 뛰는 느낌만 알면 충분해."

---

### (5) 곱셈 묶음 문장제 [새 진도 — 곱셈 활용]

딸기 우유가 한 줄에 5개씩 들어 있습니다. 8줄이 있습니다. 딸기 우유는 모두 몇 개인가요?

```
식: 5 × □ = □
```

> 부모 멘트: "'모두 몇 개'라고 했지? 같은 수가 여러 줄이니까 어떤 식이 좋을까?"

---

### (6) 말을 듣고 알맞은 식 고르기 [누적 — 문장→식 변환 🔴]

각 문제를 읽고 **계산하기 전에** 어떤 식인지 먼저 골라 ○ 하세요. 그다음 답을 구합니다.

| 문제 | + | − | × | 식과 답 |
|------|---|---|---|---------|
| 가) 사탕이 5개씩 6봉지. 모두 몇 개? | | | | |
| 나) 쿠키 30개 중 12개를 먹음. 남은 것은? | | | | |
| 다) 빨간 구슬 24개, 파란 구슬 18개. 빨간 게 몇 개 더 많나? | | | | |

> 부모 멘트: "먼저 식 모양부터 고르자. '모두'면 어떤 거? '남은'은? '더 많나'는?" — 직전 세션에 잠깐 멈췄던 부분이라 천천히.

---

### (7) 곱셈으로 묶고, 중간값 적으며 더하기 [누적 — 식 전개·중간값 🟡]

색연필이 5자루씩 7통 있고, 낱개 색연필이 18자루 더 있습니다. 색연필은 모두 몇 자루인가요?

순서대로 칸에 적어 보세요.

```
5 × 7 = □          ← 먼저 묶음을 곱셈으로
□ + 18 = □         ← 위 답(중간값)을 이 줄로 옮겨 적기
```

> 부모 멘트: "첫 줄의 답은 끝난 답이 아니라, 다음 줄로 들고 가는 **중간값**이야. 같은 수인지 위아래를 확인해 보자." (35+18에서 받아올림이 자연스럽게 나옴 — 곱셈 흐름 안의 누적 복습)

---

### (8) 4단과 5단 짧게 비교 [기초 점검 — 자연 노출]

어느 쪽이 더 많고, 몇 개 더 많은가요?

- 가: 초콜릿 5개씩 6상자
- 나: 초콜릿 4개씩 7상자

```
가: 5 × 6 = □
나: 4 × 7 = □
차이: □ − □ = □
```

> 부모 멘트: "(6)에서 연습한 대로 — '몇 개 더 많은가'는 어떤 식이었지?" ((6)과 자연 연결)

## 4. 사고력 도전 (8~10분)

> 이건 어른도 잠깐 멈춰. 끝까지 못 풀어도 괜찮아. 어디까지 생각했는지가 더 중요해.

### 도전 1 — 거꾸로 묶음 찾기 [사고 방향: 역방향 추론]

사탕이 모두 **40개** 있습니다. 한 봉지에 똑같은 수만큼 담았더니 **봉지가 8개** 나왔습니다.

- 한 봉지에 몇 개씩 담았을까요?
- 어떤 곱셈식으로 알 수 있을까요?

```
5 × 8 = 40  로도 쓸 수 있고,   □ × 8 = 40  의 □를 찾는 것과 같아요.
```

> 부모 멘트: "이번엔 답(40)을 먼저 알려 줬어. 거꾸로 한 봉지에 몇 개인지 찾는 거야." (강점인 역방향 추론을 곱셈에 연결 — 본문제와 사고 방향이 다름)

---

### 도전 2 — 5단 끝자리의 비밀 [사고 방향: 패턴 일반화]

5단 답을 차례로 적어 봅니다.

```
5×1=5   5×2=10   5×3=15   5×4=20   5×5=25   5×6=30   5×7=35   5×8=40
```

질문:
- 답의 **끝자리**만 따로 적어 보세요. 어떤 두 숫자가 번갈아 나오나요?
- 그렇다면 **5×9의 끝자리**는 무엇일까요? 계산하기 전에 규칙으로 먼저 맞혀 보세요.
- (보너스) 5×12는 못 외워도, 끝자리만은 0일까 5일까요? 왜 그렇게 생각했나요?

> 부모 멘트: "계산해서 맞히는 게 아니라, **규칙을 먼저 찾아서** 맞히는 거야. 규칙을 말로 설명할 수 있으면 대성공." (도전1과 완전히 다른 축 — 패턴을 찾아 다음을 예측. 교환법칙·체계적 탐색과 무관)

## 진행 메모
