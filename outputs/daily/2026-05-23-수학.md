## 1. 워밍업 (4~5분)

> 부드럽게 시작해요. 종이와 연필 준비. 압박감 없이, "같이 생각해보자" 톤으로.

**(워밍업1) 십 만들기 — 가까운 십으로 갈아 끼우기**
부모가 말로: "47에서 **50까지 가려면 몇이 더 필요할까?**" (→ 3)
"그럼 47 + 3 = 50이지? 50은 동그란 십이라 계산이 편해. 이게 오늘의 비밀 무기야."
한 번 더: "68에서 **70까지는 몇 더 필요해?**" (→ 2), "35에서 **40까지는?**" (→ 5)
→ 오늘 본문제로 자연스럽게 이어집니다.

**(워밍업2) 중간값에 이름 붙이기 — 두 칸 셈 맛보기**
부모가 종이에 칸 두 개를 그려 줍니다.
```
[ 23 + 8 = ___ ]  →  [ 그 답 - 5 = ___ ]
```
"먼저 왼쪽 칸을 풀고, 나온 답을 **오른쪽 칸으로 옮겨 적은 다음** 마저 풀자."
(답: 31 → 26) "방금 옮겨 적은 31을 우리는 '중간값'이라고 불러. 오늘 이 옮겨 적기를 많이 할 거야."

**(워밍업3) 구구단 짧게 (2~3분, 부담 없이)**
리듬 읽기 한 줄: "6, 12, 18, 24, 30…" (6씩 뛰며 손뼉)
빈칸 1개: "6 × 4 = ___" / "5 × ___ = 35"
랜덤 2개만 가볍게: "4 × 7 = ?", "6 × 3 = ?"
> 막혀도 그냥 같이 세어 주고 넘어가세요. 길게 끌지 않습니다.

## 2. 개념 확인 (2~3분)

**오늘의 핵심 한 줄**: 어려운 계산은 **수를 갈라 가까운 십을 만들거나(가르기)**, **중간값에 이름 붙여 다음 칸으로 옮겨** 풀면 쉬워진다.

부모가 던질 질문 1~2개:
- "47 + 19를 한 번에 더하기 어려우면, 19를 **3과 16으로 갈라서** 47을 50으로 만들면 어떨까?"
- (식 전개·등호 짚기 — 매 세션 짧게) 종이에 `47 + 19 = 47 + 3 + 16` 을 써 주고:
  "**줄을 바꿔 다르게 써도, 등호(=) 양쪽은 항상 똑같은 양이야.** 모양만 바꾼 거지 값은 안 변해. 그치?"
  → 유주가 "응, 똑같아"라고 **한 번 말로** 하게 해 주세요. (이게 오늘 식 전개 지도 전부예요. 길게 X)

## 3. 본문제 (18~22분)

> 부모가 문제를 읽어 주고, 유주가 연습장에 쓰며 풉니다. 칸을 미리 그려 주면 표상 연습이 쉬워져요.

**(1) [새 진도 — 십 만들기 과정식] 칸을 채워 50을 만들어 풀기**
종이에 이렇게 써 주세요. 빈칸을 유주가 채웁니다.
```
47 + 19 = 47 + 3 + ___ = 50 + ___ = ___
```
"19를 3과 몇으로 갈랐지? 그 몇을 빈칸에 적자." (3과 16)
→ 답: 16 / 16 / 66

**(2) [새 진도 — 십 만들기, 스스로 가르기] 이번엔 어떻게 가를지 유주가 정하기**
"38 + 25를 풀 거야. **38을 40으로 만들려면** 25에서 얼마를 떼어 와야 할까?" (2)
```
38 + 25 = 38 + 2 + ___ = 40 + ___ = ___
```
→ 답: 23 / 23 / 63
> "또 다른 방법은?" 한번 물어보세요. 25를 40으로 만들 수도 있어요(25+2... 가 아니라 38에서 떼기). 다른 길도 답이 같다는 걸 보면 좋아요.

**(3) [새 진도 — 중간값 순서도, 두 칸 옮겨 적기] 42 - 17 + 37**
칸을 두 개 그려 주세요.
```
1칸:  42 - 17 = ___
2칸:  (1칸의 답) + 37 = ___
```
"먼저 42 - 17을 풀고, 나온 **중간값을 2칸으로 옮겨 적은 다음** 37을 더하자."
→ 답: 25 → 62
> 핵심은 정답(62)이 아니라 **25를 다음 칸으로 옮겨 쓰는 행동**이에요. 25를 직접 손으로 옮겨 적게 하세요.

**(4) [새 진도 — 한 문제 두 가지 풀이] 64 - 28을 두 가지 길로**
같은 문제를 두 번, 다른 방법으로 풀어 봅니다.
- 길 ㉠ (십 만들기 빼기): `64 - 28 = 64 - 24 - 4 = 40 - 4 = ___` (28을 24와 4로 갈라 40 먼저 만들기) → 36
- 길 ㉡ (그냥 받아내림 세로셈): 64 - 28 = ___ → 36
"두 길로 풀었는데 답이 같지? **길이 달라도 도착지는 같아.**" (등호 의미 한 번 더 자연 노출)

**(5) [새 진도 — 거꾸로 풀기 / □식 역연산] 빈칸을 찾아라**
부모가 읽어 줍니다: "어떤 수에 19를 더했더니 **71**이 되었어. 어떤 수는 얼마일까?"
```
___ + 19 = 71
```
"더하기로 막혔으면 **거꾸로** 생각하자. 71에서 19를 빼면?" → 답: 52
> 유주가 71 - 19 = 52로 거꾸로 푸는 걸 좋아할 거예요(이미 □식 강점). "왜 빼기로 바뀌었을까?"를 한 번 물어보세요.

**(6) [누적 — 받아올림/내림, 단원 흐름에 자연 연결] 십 만들기로 받아올림 자연스럽게**
"86 + 37을 십 만들기로 풀어 보자. 86을 90으로 만들려면 37에서 얼마를 떼지?" (4)
```
86 + 37 = 86 + 4 + ___ = 90 + ___ = ___
```
→ 답: 33 / 33 / 123
> (받아올림이 백의 자리까지 가는 계산을 **십 만들기 흐름 안에서** 다시 만났어요. 단발 끼워넣기가 아니라 오늘 무기로 같은 계산을 한 거예요. 5-11 평가에서 86+37은 맞혔으니, 오늘은 "과정식으로도 쓸 수 있다"를 확인하는 거예요.)

**(7) [누적 — 문장→식 변환 + 곱셈 자연 노출] 어떤 식이 맞을까**
부모가 읽어 줍니다:
"바구니에 사과가 **6개씩 4묶음** 있었어. 거기서 동생이 **8개**를 먹었어. 지금 사과는 몇 개?"
먼저 물어보세요: "처음 사과 개수는 더하기일까, **곱하기**일까?" (6 × 4)
"먹은 건 더할까 뺄까?" (빼기)
```
6 × 4 = ___ (중간값)  →  ___ - 8 = ___
```
→ 답: 24 → 16
> 곱셈(6×4)은 여기서 **딱 한 번 자연 노출**됩니다. 도배하지 않아요. 중간값 24를 다음 칸으로 옮겨 적게 하세요(오늘 핵심 표상 재등장 — 단, (3)과 다른 맥락=문장제라 중복 아님).

**(8) [기초 점검 — 구구단 짧게] 곱셈식 빈칸 한 줄**
가볍게 한 줄만. "5 × ___ = 30", "6 × ___ = 18"
→ 답: 6 / 3
> 30초 안에. 막히면 워밍업 리듬으로 같이 세어 주고 넘어가세요. 이게 오늘 구구단의 전부예요.

> 사고력 유형 자체 확인: (1)(2) 가르기 패턴②, (3)(7) 중간값 순서도·문장제⑧, (4) 여러 풀이, (5) 거꾸로 풀기⑨ → 사고력 유형이 본문제 8개 중 6개. 50% 이상 충족.

## 4. 사고력 도전 (6~8분)

> "이건 어른도 잠깐 멈춰. 끝까지 못 풀어도 괜찮아. **어디까지 생각했는지가 중요해.**"
> scaffolding은 처음엔 주지 말고, 1분쯤 스스로 표상을 떠올리게 기다려 주세요. 막히면 아래 힌트를 **점점 작게** 주세요.

**(도전1) [사고 방향: 거꾸로 풀기 / 역연산] 사라진 처음 수**
부모가 천천히 읽어 줍니다:
"유주가 사탕을 몇 개 가지고 있었어. 친구한테 **17개를 줬고**, 그다음 엄마가 **9개를 더 줬어**. 그랬더니 지금 **24개**가 됐어. **처음에 사탕이 몇 개 있었을까?**"

- 1단계 힌트(필요할 때): "마지막이 24개야. **거꾸로 거슬러 올라가 보자.** 마지막에서 9개를 받았으니, 받기 전에는?" (24 - 9 = 15)
- 2단계 힌트: "그 전에 17개를 줬었지? 주기 전에는 더 많았을 거야." (15 + 17 = 32)
→ 답: **32개**
> 거꾸로 가면 받은 건 빼고, 준 건 더해요. 순서도로 그려도 좋아요:
> `처음 ?  →(-17)→  ?  →(+9)→  24`. 이걸 오른쪽 끝부터 거꾸로 채워 보게 하세요.

**(도전2) [사고 방향: 체계적 탐색 — 빠짐없이 모두 찾기] 두 칸의 합이 같게**
> (도전1과 다른 축입니다. 도전1=역방향 추론, 도전2=경우를 빠짐없이 세는 체계적 탐색. 유주의 약점인 "0 케이스·큰 짝 누락"을 부드럽게 건드립니다.)

"두 빈칸에 수를 넣어서 **합이 10이 되게** 만들 거야. 두 칸에 들어갈 수는 **0부터 10까지** 쓸 수 있어. **순서가 다르면 다른 것으로 쳐.** (예: 3과 7, 7과 3은 둘 다 세기)"
```
___ + ___ = 10
```
"몇 가지 방법이 있을까? **하나도 빠짐없이** 찾아보자."

- 힌트(스스로 못 시작하면): "**첫 칸을 0부터 차례로** 정해 보자. 첫 칸이 0이면 둘째 칸은? 1이면? 2면?... 표를 만들면 안 빠뜨려."
→ 답: (0,10) (1,9) (2,8) (3,7) (4,6) (5,5) (6,4) (7,3) (8,2) (9,1) (10,0) → **모두 11가지**
> 유주가 0과 10을 빠뜨릴 가능성이 높아요(0 케이스·끝값 누락이 누적 약점). "**0도 써도 된다고 했지? 10도?**" 한 번 짚어 주세요. 정답 개수보다 **"첫 칸을 0부터 차례로"라는 탐색 전략을 스스로 쓰는지**를 봐 주세요.
