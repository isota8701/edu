- 진행: 누적 단어 회전 6개(cat·cap·map·hat·bag·dad) + f/p 미니 게임(fan·fox·pan·pig) + 단모음 a 손가락 세 번 읽기(ham·van) + 신규 3개(ham·van·tag) + 사이트워드(see 신규 + is·this·it·a 누적) + 회화 "I see a ___ / What do you see?" + 듣기·읽기·분류·쓰기 + 받아쓰기 2문장(It is a ham. / I see a van.)

**부모 보고 핵심 (2026-05-17)**:
1. **쓰기 자체가 체계 부족** — 마지막 문장 받아쓰기에서:
   - **h를 어떻게 쓰는지 모름** (글자 형태 자체)
   - **v를 써야 하는데 b를 쓰려 했는데 막상 d를 씀** — 쓰기 단계에서부터 b/d 혼동, 그게 읽기 혼동으로도 이어지는 듯
   - **파닉스처럼 쓰기 또한 체계적으로 배운 적이 없음** → 글자 모양·획 미니 트랙 필요
2. **사이트워드 진전·정체 분리**:
   - **is — 이제 머리속에 익힌 듯** (🔴 → 🟢 안정화 진입)
   - **this — 여전히 자주 까먹음** (🔴 유지)
   - **the — 발음을 자주 잊어버림** (🔴 유지)
3. **현재 형식 부모 만족 → 유지**: 단어 → 회화 → 문장 읽기 → 단어 쓰기 → 문장 받아쓰기. 5단계 흐름 그대로 가져간다.
4. **단모음 진도는 시스템 판단으로 진행** (부모 위임).

**다음 세션 방향 (D24, 2026-05-17 갱신)**:
- **알파벳 소문자 쓰기 미니 트랙 신설** — 매 세션 1~2글자 짧게. 우선순위 **h, v, b, d**(받아쓰기에서 막힌 글자부터). 단순 따라쓰기 X — 글자 모양(b 배 오른쪽/d 배 왼쪽, h는 막대+언덕, v는 뾰족한 골) 한 줄로 짚고 따라쓰기 2~3개. 쓰기 트랙 안에 통합.
- **is는 유지 점검만** — 받아쓰기 단골 회전, 새 문장에서도 자연 노출. 트래커는 🟡로 강등.
- **this·the는 매 세션 등장 필수** — this는 받아쓰기 단골, the는 발음 시범 매 세션 한 번. 카드 + 문장 속 + 들으며 따라하기 다중 채널.
- **단모음 진도(부모 위임)**: 단모음 a를 한 세션 더(5세션) 마무리한 뒤 6세션부터 단모음 i 도입 검토(짧은 i는 a 다음으로 가장 흔하고 CVC 어휘량이 풍부). a 단어 누적 회전은 유지하면서 i 단어 신규 2~3개 점진. 단, **this·the·쓰기 약점이 너무 무거우면 단모음 진도는 한 세션 더 미루고 안정 우선**.
- **자음 트랙은 f/p 결과 보고 후 다음 쌍(m/n 또는 v/w) 결정**. b/d는 쓰기 단계에서 글자 모양 미니 점검과 결합.
- **5단계 형식 유지** — 부모 만족. 단계 추가·삭제 없이 길이·난이도만 조정.
