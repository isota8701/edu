## 2. 곱셈의 의미 + 4·5단 정착

- **기간**: 3주 (6~7세션)
- **핵심 개념**: 곱셈 = 같은 수 반복 더하기 / 묶어 세기 / 직사각형 배열 모델 / 교환법칙(4×3 = 3×4)
- **학교 진도 sync**: 1학기 곱셈 도입과 동기화
- **시작 진단** (1세션 첫 5분): "사과 4개씩 3묶음 → 모두 몇 개?" + 4단 5문제 + 5단 3문제 (5단 노출 후 첫 반응 보기)
- **종료 평가**: 8문제 (곱셈 모델 추론 3, 곱셈식↔덧셈식 변환 2, 4·5단 자동화 3 — 통과 6/8)
- **세션 패턴**:
  - 워밍업: 5단 신규 노출 + 4단 누적 랜덤 (2~3분)
  - 본문제: 묶음 그림→곱셈식, 곱셈식↔덧셈식, 직사각형 배열에서 식 만들기, 5단 활용 묶음 응용
  - 도전: "4×3과 3×4가 왜 같을까? 그림으로 설명" / "5×4 ≠ 5+4를 그림으로 보여주기"

### 5단 도입 페이스
- 1세션: 5단 = 5씩 뛰기와 같음을 보여주기 (5, 10, 15, 20…). 5×1 ~ 5×5만.
- 2세션: 5×6 ~ 5×9 추가. 5의 배수 패턴(끝자리 0 또는 5).
- 3세션: 5단 랜덤 응답 시도. 막힘 1초 이상이면 △.

## 3. 두 자리 덧뺄셈 사고력 응용

> **원장 반영 (D29, 2026-05-28)**: 두 자리 **뺄셈은 약점**(학원 숙제 오답율 높음). **뺄셈을 덧셈과 같은 "십 만들기"로 가르치지 않는다** — 세 갈래로 분리: ① **보정**(빼는 수를 가까운 십으로 올려 빼고 도로 더하기, `62-28=62-30+2`), ② **십 만들기(한 자리만 남기기)**(`71-38=71-30-8=41-8=41-1-7=40-7`), ③ **세로셈(기본)**. 철칙: "십을 만든 뒤 빼는 양이 한 자리로 줄 때만" 쉬워진다(`60-26`처럼 두 자리 남으면 금지). 그리고 **규칙·수열**(학원 3테마 중 양호)을 이 단원에 함께 회전하되 사고력 난도(내려가는 수열로 뺄셈 연습·간격 증가·두 규칙 번갈아)를 섞어 **약점(뺄셈)을 강점(수열) 형식 안에 녹인다.** 자세한 원칙은 `math-tutor.md` "원장 반영 원칙" 참조.
>
> **원장 반영 (D30, 2026-06-04)**: 2세션(5-28) 관찰 두 가지를 추가 반영. ① **연산 식별 메타인지** — 받아내림 뺄셈만 연속하니 받아내림 없는 뺄셈도 기계적 세로셈으로·받아올림 덧셈에서 헷갈림. 본문제 세트에 **덧셈·뺄셈(받아올림/내림 유무)을 섞고**, 풀기 전 "더하기야 빼기야? 받아올림/내림 있어?"를 **말로 짚게** 한다(같은 연산 연속 도배 금지). ② **거꾸로 풀기는 도전→본문제급으로 강등** — 거꾸로 풀기 도전이 5-16·5-26·5-28 3세션 흔들림. scaffolding 순서도 칸 채우기 본문제(`처음 ?→(-18)→?→(+25)→41`)로 내려 표상 정착 후 다시 도전으로. (자신감 보호.) `math-tutor.md` "원장 반영 원칙" 참조.

- **기간**: 2주 (4~5세션) — 뺄셈 약점 보강으로 5세션+ 가능
- **핵심 개념**: 받아내림 안정화 + **뺄셈 전략 3갈래(보정·십 만들기 한 자리·세로셈) 분리 지도** + "어떤 길이 똑똑한가" 선택 + 거꾸로 풀기 + 빈칸 채우기 + **규칙·수열 사고력**
- **학교 진도 sync**: 1학기 덧뺄셈 단원과 동기화 (이미 학교에서 진행 중)
- **시작 진단**: 받아내림 1문제 + 받아올림 1문제 (속도 측정)
- **종료 평가**: 5문제 (받아내림 2 — 보정·십만들기 각 1, 전략 선택 1, 거꾸로 풀기 1, 수열 사고력 1)
- **세션 패턴**:
  - 워밍업: 보정 준비(가까운 십·몇십 빼기) + 십 만들기 준비(한 자리 빼서 십) + 구구단 짧게

  - 본문제 B(규칙·수열): 쉬운 등차 1 + 사고력 2~3(내려가는 수열·간격 증가·두 규칙 번갈아)
  - 도전: 거꾸로 풀기 문장제(확신+검산) + 사고력 수열

## 4. 길이 재기 (cm·m)

> **원장 반영 (D30, 2026-06-04)**: 학교가 이미 길이 단원에 진입(5-28 시험)했고 오답 3건이 나왔다 — **측정 기능이 아니라 ①단위 감각 ②어림 ③비교 문장 논리 약점**. 도입을 **6월 초로 앞당기고**(3단원 마무리와 병행해 워밍업 맛보기부터), 단원을 세 축으로 짠다. 특히 **비교 문장 논리**("어림이 잰 것보다 더 ___"를 한 조각씩 끊어 읽기)는 길이를 넘어 문장제 전반에 전이되는 범용 약점이라 이 단원을 그 훈련의 그릇으로 쓴다. `math-tutor.md` "원장 반영 원칙" 참조.

- **기간**: **2주 (3~4세션) — 6월 초 앞당김**. 3단원 후반과 워밍업 맛보기로 겹쳐 부드럽게 진입.
- **핵심 개념 (세 축)**:
  1. **단위 감각** — cm·m 의미 + **재려는 대상 크기에 맞는 단위 고르기**(작은 것엔 작은 단위). "어떤 단위로 잴까?" "모두 고르기"에서 후보를 하나씩 따져 과다 선택·누락 둘 다 점검. *(5-28 오답①: 짧은 길이 잴 단위로 1~5 전부 고름)*
  2. **어림** — 기존 강점 **수직선 거리 감각을 cm·근사에 연결**("27cm는 22와 30 중 어디에 더 가까울까?"). 어림 후 실측 비교. *(5-28 오답③: 27cm를 22cm로)*
  3. **비교 문장 논리** — "무엇이 무엇보다 더 ___인가"를 **한 번에 한 조각씩 끊어 읽기**. 어림↔측정 비교를 천천히. *(5-28 오답②: 4<5인데 "더 깁니다")*
  - (계산 축) cm·m 측정·환산(1m=100cm)은 위 세 축에 얹어 가볍게.
- **학교 진도 sync**: 1학기 길이 단원 — **이미 진행 중**(5-28 시험 확인).
- **시작 진단**: "연필 길이 어림하기" 1문제 + "이걸 잴 단위로 알맞은 것 고르기" 1문제(단위 감각)
- **종료 평가**: 4문제 (단위 감각 1, 어림·근사 1, 비교 문장 논리 1, 측정·환산 1)
- **세션 패턴**:
  - 워밍업: 단위 감각 퀴즈("연필은 cm? m?") + 누적 구구단 짧게
  - 본문제: 대상에 맞는 단위 고르기, 어림 후 실측 비교(수직선 거리 감각 연결), 비교 문장 한 조각씩 읽기, 측정·환산
  - 도전: "교실 가로가 약 8m라면 책상 몇 개를 가로로 놓을 수 있을까?"(어림+나누기 감각)
