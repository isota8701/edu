# 학습 로그 (git graph 뷰)

한 줄 = 한 세션. **최신이 맨 위.** `/done` 호출 시 맨 위에 한 줄을 추가한다.

```
범례   📐 수학   📖 국어   🔤 영어   🔬 과학·인문   ◇ 메타(외부 피드백·평가, daily 파일 없음)
형식   * YYYY-MM-DD  {아이콘} {과목}   핵심 결과 · 관찰  →  다음 보강
```

상세 회차 기록은 `outputs/progress.md`(세션 로그·누적 복습 트래커), 아이 상태는 `student/profile.md` 참조.
