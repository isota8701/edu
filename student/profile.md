### 오답 누적 패턴
- **"모두 찾기" 문제에서 누락 — 0 케이스(2026-04-29) + 큰 인수 쌍(2026-05-04 10×2)** — 같은 계열의 "체계적 탐색 약점". 작은 후보에서 멈추는 경향. 출제 시 "1부터 차례로 시도해볼까?" 한 번 시범.

- **도전 독립 진입은 아직 (2026-05-16)** — 본문제는 전부 맞히나, 도전1은 □×8=40 표상으로 바꿔 줘야, 도전2 변형(5×21·5×48 일의 자리)은 "곱하는 수 홀짝" 분류 힌트를 줘야 도달. 큰 인수 유도 필요와 같은 계열 — 표상·분류 기준을 스스로 세우는 단계로 점진 이행 필요(힌트 점감).
- **도전 약점이 "표상 못 세움" → "실행 확신 부족"으로 이동 (2026-05-26)** — 도전1(사라진 처음 수)에서 거꾸로 풀기 접근을 **스스로 맞게 세웠다.** 다만 확신이 없어 계산 중 틀림. 진전된 약점이므로, 막힘이 아니라 **자기 풀이를 믿고 끝까지 가서 검산하는 습관**으로 대응(부정적 교정 X — "방법 맞았어, 한 번 더 천천히").
- **거꾸로 풀기 문장제 2세션 연속 약점 (2026-05-28)** — 같은 유형(사라진 처음 수)을 5-28엔 다시 틀림. "한 단계 진전"이 안정으로 이어지지 못함 → 도전 난도로는 이르다. **순서도 채우기 본문제(scaffolding)로 한 걸음 내려** 표상을 먼저 정착시킨 뒤 도전으로 복귀.
- **덧셈·뺄셈 혼합 시 메타인지 흔들림 (2026-05-28)** — 받아내림 뺄셈만 연속하면 받아내림 없는 뺄셈도 기계적 세로셈으로 풀거나 받아올림 덧셈에서 헷갈림. 계산력이 아니라 "지금 무슨 연산인지" 자각이 한 연산 연속 시 흐려지는 문제 → 혼합 출제 + 풀기 전 말로 짚기.
- **길이 단원 — 긴 문장 비교 논리 + 단위·근사 (2026-05-28 학교 시험)** — 어림 vs 잰 길이 비교에서 4<5인데 "더 깁니다"로 오답. **긴 문장을 읽고 논리적으로 판단하는 힘 부족**(부모 분석)은 길이를 넘어 문장제 전반의 신호. 단위 "모두 고르기" 과다 선택은 체계적 판단 계열, 어림 근사(27→22 선택)는 수직선 거리 감각 미연결.

- **단어 흡수**: 누적 회전 a 단어(cat·van·tag 등)는 무난, **받아쓰기로 복습 회전해 정착**(부모 전략). **6-03 단모음 i 첫 진입 — sit·pig·big 잘 익힘.** 다음 세션 i 단어 한 번 더 확장 + a 단어와 섞어 읽기. 한 세션 새 모음 1개 유지.
- **사이트워드**:
  - **is — 안정 (🟢)**. 가벼운 확인만.
  - **this — 읽기·받아쓰기 모두 어려움 (🔴 유지)**. 삼중고(소리 ㄷ≠철자 th / th 일반발음 θ과 ð 충돌 / b/d 겹침). **통단어 암기로** 카드+문장+받아쓰기 회전. th 규칙 설명 금지. 막히면 카드 즉시 제시.
  - **the — 🔴 유지**. 6-03 읽기·받아쓰기 어려움(this와 함께). 발음(더) 시범 유지. this와 같은 th 통단어 묶음.
  - **see — 점검 (🟡)**. 6-03 "I see the big bag."에 재등장, 실패 보고 없음.
- **응용력**: 패턴 들어도 새 단어에 적용은 여전히 느림. 음운 인식·자력 디코딩 진행 중.
- **문법**: is/are, have/has 부정확
- **말하기·회화 (부모 평가 긍정 유지)**: "What's this? / It's a ___ / I see a ___" 패턴 도움 됨. 맥락형 회화 확대 유효.
- **듣기**: 쉬운 표현 부분 이해, input 노출량 부족
- **쓰기**: 위 "쓰기 — 새 약점" 항목 참조. **시스템 차원에서 글자 형태 미니 트랙 필요**.
- **Dr. Seuss류**: 반복으로 외워서 읽은 것으로 재해석. 자력 디코딩 단계 아님.

### 지도 환경
- 부모가 영어권 거주 경험 → 발음·프리토킹 지도 가능

### 시스템 진행 방향 (D24, 2026-05-17 갱신)
- **5단계 형식 유지 (부모 만족)** — 단어 → 회화 → 문장 읽기 → 단어 쓰기 → 문장 받아쓰기. 단계 추가·삭제 없이 길이·난이도만 조정.
- **알파벳 소문자 쓰기 미니 트랙 (D24, 2026-05-26 갱신)** — 매 세션 1~2글자 짧게. h·v는 5-26 도입 완료(점검 단계). **다음 우선순위: b/d(지속) + g·t(신규 약점)**. 단순 따라쓰기 X — 글자 모양(b 배 오른쪽/d 배 왼쪽, g 동그라미+아래 꼬리, t 세로 막대+가로 한 줄) 한 줄로 짚고 따라쓰기 2~3개. **읽기는 되는데 쓰기가 안 되는 글자(g·t) 우선.** 쓰기 트랙 안에 통합.
- **신규 단어는 매 세션 2~3개로 점진 확장**. 단어량은 영어 실력 핵심이므로 늘려가는 방향 유지.
- **누적 회전 강화** — 정착 안 된 단어는 매 세션 워밍업·문장·회화·게임에 등장. 정착된 단어는 가끔 점검.
- **자음 혼동 미니 트랙** — b/d 지속, f/p(2026-05-17 도입) 결과 보고 후 다음 쌍(m/n 또는 v/w) 결정. 매 세션 2~3분.
- **사이트워드 차등 운영 (2026-05-26 갱신)** — is는 안정(🟢, 가벼운 확인만). this·the는 매 세션 등장(🔴) — **th 규칙 설명 금지, 통단어로 암기**(this 삼중고 때문). 다중 채널: 카드 + 문장 속 + 받아쓰기 + 발음 시범.
- **맥락형 회화 확대** — 1세션당 1상황. "I see a ___" 신규(5-17), "What's this? / It's a ___ / Is this a ___?" 누적.
- **영어 받아쓰기 미니 트랙** — 매 세션 마지막 2~3분, 그날 배운 범위 2~3문장. 사이트워드(this·the·it·see)를 받아쓰기 단골로. ⚠️ **국어 받아쓰기(부모 전담·시스템 X)와 별개**.
- **단모음 진도 — a 마무리, i 도입 확정 (2026-05-26 부모 제안)** — 부모: "이제 a(애)에서 다른 발음으로 넘어가는 게 좋겠다." 5세션으로 단모음 a 마무리, **6세션부터 단모음 i(sit·pig 등) 본격 도입**. a 단어는 누적 회전으로 유지, i 신규 2~3개 점진. 한 세션 새 모음 1개만.
- 이중모음(ai/ea/oo 등)은 단모음·자음·사이트워드 안정 후 진입.
- 4기능 균형 유지하되 듣기·읽기에 살짝 더 비중 (input 우선)
- 한 세션에 새 패턴 1개만, 같은 단어를 여러 맥락에서 반복 노출.

### 취약 포인트 (2026-06-03 재정렬)
1. **소문자 쓰기 — 읽기는 되는데 쓰기가 안 됨**: **b/d 6세션째 지속(읽기·쓰기 모두)** + **h·p 헷갈림(2026-06-03; h 재부상·p 신규)**. g·t는 도입 진행(점검), v 점검. 다음 쓰기 트랙 우선순위 = b/d + h·p. 모양·획순 한 줄씩(p는 b·d와 방향 혼동 주의).
2. **this·the 읽기·받아쓰기 (2026-06-03)** — 삼중고(①소리 'ㄷ'≠철자 th ②th 일반발음 θ과 ð 충돌 ③b/d 겹침). 6-03 읽기·받아쓰기 모두 어려움. **th 규칙 가르치지 말고 통단어 암기.** 막히면 카드 즉시 제시. is는 안정(🟢).
3. **글자→소리 자력 변환 (소리 합치기)** — 복습 a 단어는 진전, **단모음 i 첫 진입은 성공(sit·pig·big)**. 신규는 여전히 느리나 i 도입 무난.
4. **영어 받아쓰기 정착도** — b/d·this·the 약점이 받아쓰기에서 노출 + **기존 a 단어 복습 정착 도구로 작동**(부모 전략). 약점 발견 + 복습 이중 도구. 매 세션 2~3문장 유지.
5. **단어 절대량** — 복습 a 단어 무난(받아쓰기 회전). **단모음 i 신규 확장(6-03 sit·pig·big → 다음 세션 한 번 더 + a와 섞어 읽기).**
6. 이중모음 (보류, 더 후순위)
